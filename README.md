# Pharmacy Assessment

Pharmacy Medicine Management System built using:

- .NET Core Web API
- C#
- React
- TypeScript
- JSON file storage

## Features

- View medicines
- Add medicines
- Search medicines by name
- Record medicine sales
- Stock validation
- Expiry warning
- Low-stock warning

## Backend

cd Pharmacy.Api
dotnet restore
dotnet run

API:
http://localhost:5274

## Frontend

cd pharmacy-ui
npm install
npm run dev

Application:
http://localhost:5173
